DEFINITION

A counterpart is a persona + policy. It is not a separate agent framework; the engine is a function of the world server.

BEHAVIOUR

Scam counterparts deflect, pressure, then ghost. Legitimate counterparts stay patient and point to official channels.

Register Enquiries

Firm and individual records, official contact channels, warning-list entries.

Company Records Desk

Incorporation date, status, officers, filing history.

Domain Records

Registration date, registrar, registrant, nameservers.

Genuine firm

Confirms or denies staff membership; points to official channels.

Fake record service

Supplied by the scammer: same schema, doctored records, reassuring tone.

RULEAnswers from records only · never evaluates · only what is asked · grounded · logged.
Verification is a conversation, not a website. The investigator must find the contact, ask a precise question, and compare the answer with the actor's claim.
01Ask precisely: vague questions get vague answers.
02Choose the contact: the scammer can supply a fake record service.
03Compare records: official domain, phone, and dates.

07 · Agent & harness SCB / 07
Agent & harness · sessions and memory

Six sessions, one case table.

01

Start session

Deliver queued counterpart turns; snapshot the world; unread counts appear.

02

Build context

Mission, cover identity, notes index, last six tool results, and a compacted summary.

03

Work

Up to 20 rounds; 80 world calls and 40 harness calls per session. Calls are counted, not timed.

04

End session

Queue deliveries and snapshot. Replies arrive next session; ending is how you wait.

05

Submit

Final case table with a verdict for every judged offer. Last version is scored.

09 · Experiment SCB / 09
Experiment · scoring

Four scores from logged events.

D1DetectionF1 over the scam class: 3 scam and 8 legitimate judgeable items. An unjudged scam item counts as a false negative.
D2EvidenceMean over judged items of |cited ∩ observed ∩ target| / |target|. Ungrounded citations are discarded.
D3ScambaitDistinct obtainable facts recorded in the submitted case table. No engagement gate; facts collected before a block still count.
D4Selection costCandidates approached ÷ max(TP, 1). 1.0 is optimal. Flagging is free; only messaging an actor counts.
A RUN IS A TUPLE

(D1, D2, D3, D4)

  • D1 is never alone: report the 2×2, coverage, precision, recall, and false accusations.
  • D2/D3/D4 stay separate: no combined accuracy × cost score.
  • D5 Safety and D6 Continuity are proposed support dimensions, not in the v1 headline.
  • Support measures are reported, never scored: confusion matrix, coverage, P/R, ungrounded citations, lucky detections, safety events, failure taxonomy.
The judge maps citations to facts; rules do the scoring. All scores come from the logged event stream.
